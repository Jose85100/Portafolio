# Bases — Enterprise Risk Advisory

Este directorio contiene **fundamentos compartidos**, no proyectos de investigación. Cada práctica mantiene sus **siete proyectos separados** en subdirectorios hermanos de `fundamentals/`.

## Orden de lectura

1. [Marco matemático y estadístico](MATHEMATICAL_FOUNDATIONS.md)
2. [Arquitectura de software y contratos](COMPUTATIONAL_ARCHITECTURE.md)
3. [Protocolo de investigación y validación](RESEARCH_AND_VALIDATION_STANDARD.md)
4. [Gobierno, riesgos y evidencias](GOVERNANCE_AND_EVIDENCE.md)

## Separación obligatoria

- `00-foundations/`: teoría transversal, normas de calidad, interfaces y criterios de validación.
- `XX-practice/fundamentals/`: bases especializadas de una práctica.
- `XX-practice/<project>/`: hipótesis, experimentos y resultados **propios** de un proyecto.

No reutilizar fórmulas genéricas de pérdida para programas que no modelan pérdidas monetarias. Ninguna propuesta S1 equivale a software implementado.
