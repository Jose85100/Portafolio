## Research question and baseline

Does checking that all adjacent transitions are individually approved guarantee that the **complete trace** is approved? No. The hybrid `intake → validate → manual_review → approve → notify → archive` uses locally permitted transitions but matches none of four authorized complete paths.

The executable engine uses minimum unit-cost Levenshtein distance over the four explicit paths, versus `activity_set`, `direct_follows`, and a negative ablation `alignment_tolerant` (accept distance ≤1). These are known techniques; no new global algorithm is claimed.
