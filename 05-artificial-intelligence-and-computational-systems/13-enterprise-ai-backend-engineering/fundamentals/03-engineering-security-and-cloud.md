# Engineering, identity, cloud and secure development

Reference stack: Kotlin + Spring Boot for API/control plane, Rust + Tokio/Axum for async workers, Python for ML/RAG evaluation, PostgreSQL for durable state, Redis for bounded caches, NATS/Kafka for messaging where justified, Docker and CI for reproducible deployment. Prefer a modular monolith until independent scaling or fault boundaries justify microservices. OAuth 2.0 handles authorization delegation; OIDC identity assertions; RBAC/ABAC resource authorization; PKCE for public clients; service mTLS/workload identity; token issuer/audience validation and rotation. Define secrets handling, network isolation, tenant-aware data access, encryption, data retention, SBOM, dependency provenance, SAST/DAST and threat modeling. Enforce OpenAPI versioning, OpenTelemetry traces, retry budgets, circuit breakers, idempotency and outbox patterns. AI tools operate in least-privilege sandboxes with mandatory human review for high-impact changes.
