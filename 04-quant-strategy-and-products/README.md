# Estrategia cuantitativa y productos financieros

Esta carpeta reúne herramientas para tomar decisiones de asignación, valoración y gestión del riesgo de inversión.

## Trabajo disponible

- [Gestión de portafolios](asset-management/): Markowitz, Black-Litterman, paridad de riesgo, rebalanceo y atribución.

Me interesa comparar estrategias bajo restricciones realistas: costos, rotación, error de estimación y cambios de régimen. Un backtest sintético permite inspeccionar la mecánica; no constituye evidencia de rentabilidad futura.

Los motores de riesgo en C++ se desarrollan en un pull request independiente y no se presentan aquí como integrados.
