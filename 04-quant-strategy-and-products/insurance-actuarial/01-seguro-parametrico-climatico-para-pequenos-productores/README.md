# Seguro paramétrico climático para pequeños productores

**Estado: idea de investigación.** Esta carpeta organiza la propuesta existente; no afirma implementación, datos, resultados ni validación.

## Propuesta

- Modelar pago a partir de lluvia, temperatura o humedad satelital y comparar índices con pérdidas observadas.
- Núcleo: minimizar riesgo de base entre indemnización paramétrica y pérdida económica; cuantificar asequibilidad y solvencia.

## Contraste propuesto

**Referencia:** Umbral climático único o índice de precipitación simple.

**Enfoque planteado:** Índice paramétrico multi-señal que minimiza riesgo de base con límites de prima y datos observables.

**Evaluación propuesta:** Comparar pérdida no cubierta, prima y cobertura por zona frente al índice simple; validar con pérdidas independientes.

**Prueba decisiva:** pendiente de definir con hipótesis falsable, datos, métrica y criterio de aceptación.
