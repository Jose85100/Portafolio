# Diseño de incentivos para redes de pago

**Estado: idea de investigación.** Esta carpeta organiza la propuesta existente; no afirma implementación, datos, resultados ni validación.

## Propuesta

- Optimizar comisiones, recompensas y subsidios entre comercios, adquirentes y usuarios considerando elasticidad y efectos de red.
- Comparar equilibrio de un lado con modelo de plataforma multi-lado y escenarios de adopción.

## Contraste propuesto

**Referencia:** Tarifa/subsidio unilateral sin respuesta del otro lado.

**Enfoque planteado:** Precio multi-lado que modela externalidades y equilibrio de adopción.

**Evaluación propuesta:** Comparar contribución y adopción a nivel red con tarifa base y escenarios de subsidio.

**Prueba decisiva:** pendiente de definir con hipótesis falsable, datos, métrica y criterio de aceptación.
