# Nowcast de actividad a partir de textos y anuncios

**Estado: idea de investigación.** Esta carpeta organiza la propuesta existente; no afirma implementación, datos, resultados ni validación.

## Propuesta

- Construir indicadores de demanda, inversión, empleo o precios desde comunicados, vacantes y noticias económicas.
- Contrastar con estadísticas oficiales usando vintages, cobertura geográfica y retrasos de publicación.

## Contraste propuesto

**Referencia:** Indicadores oficiales rezagados sin texto.

**Enfoque planteado:** Texto de alta frecuencia integrado en modelo mixto con disponibilidad archivada.

**Evaluación propuesta:** Validar nowcast pseudo-real-time contra modelo oficial-only; controlar revisiones y cobertura.

**Prueba decisiva:** pendiente de definir con hipótesis falsable, datos, métrica y criterio de aceptación.
