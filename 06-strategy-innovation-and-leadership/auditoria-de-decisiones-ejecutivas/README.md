# Auditoría de decisiones ejecutivas

Este proyecto reúne el análisis de sensibilidad de 15 motores de estrategia, financiación y gobierno. El [notebook](weekly-decision-audit.ipynb) utiliza entradas sintéticas y evalúa restricciones y cambios de decisión; no representa decisiones observadas ni recomendaciones de inversión.

El notebook busca la carpeta `06-strategy-innovation-and-leadership` desde el directorio de ejecución y utiliza los motores de los proyectos temáticos correspondientes. Requiere Python con NumPy, pandas, matplotlib e IPython.
