# Ficha de caso: análisis, responsabilidad y decisión

**Estado inicial: pendiente de completar con evidencia.**

| Campo | Contenido requerido |
|---|---|
| Empresa o iniciativa | Nombre autorizado o anonimizado |
| Fecha y objetivo | Periodo, problema y restricciones |
| Responsabilidad personal | Diseño, extracción, modelación, validación o recomendación efectivamente realizados |
| Trabajo de terceros | Aportes del equipo y responsables de aprobación |
| Datos y fuentes | Artefactos, permisos, fecha, moneda y calidad |
| Análisis | Presupuesto, caja, fondeo, valoración o inversión; método y supuestos |
| Alternativas | Opciones comparadas y escenarios |
| Hallazgo | Resultado cuantificado y reproducible |
| Decisión apoyada | Quién decidió, qué decidió y en qué fecha; si solo hubo propuesta, decirlo |
| Resultado observado | Evidencia posterior; separar proyección de realización |
| Limitaciones | Incertidumbre, datos proxy y dependencias |
| Evidencia | Enlaces autorizados y comandos de reproducción |

## Guion para entrevista

“En [iniciativa y periodo], fui responsable de [contribución verificable]. Construí [análisis] con [fuentes y supuestos]. Comparé [alternativas] y encontré [resultado respaldado]. Esto apoyó [decisión y responsable]. El resultado observado fue [evidencia], con [limitación].”

Es una plantilla, no una declaración de experiencia ya acreditada.
